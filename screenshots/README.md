# Screenshots

Place the following images here before pushing to GitHub:

| Filename | Description |
|----------|-------------|
| `dashboard.png` | Streamlit home page with KPI metrics and deadline countdown |
| `langflow_workflow.png` | LangFlow pipeline diagram (export from LangFlow canvas) |
| `architecture.png` | System architecture diagram |

## How to capture

### dashboard.png
Run `streamlit run app.py`, navigate to the **Home** page, and take a full-page screenshot.

### langflow_workflow.png
Open `langflow_workflow.json` in [LangFlow](https://www.langflow.org/), then use **Export → PNG**.

### architecture.png
Export the architecture diagram from the project presentation (`AICTE_Grant_Finder_Presentation.pptx`) slide as a PNG, or use the HTML artifact generated by IBM Bob.
